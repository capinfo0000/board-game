# 仕様まとめ（ノイ NEU Web アプリ）

## 概要仕様

| 項目 | 内容 |
|---|---|
| 言語 | JavaScript（JSX / ES Modules）・HTML・CSS |
| DB | なし（サーバーレス。効果音ON/OFF等の設定のみ localStorage に保存） |
| フレームワーク | React 18 ／ Vite 5 ／ PeerJS（P2P 通信） |
| OS | 不問（モダンブラウザで動作・PC / スマホ両対応） |
| その他 | Web Audio API（効果音）／ Web Speech API（読み上げ）／ GitHub Actions（自動デプロイ）／ GitHub Pages・静的ホスティング（CoreServer 等） |
| フェーズ | リリース済み（ステージ①②完了・本番公開中） |

## 備考

### 背景
「既存のボードゲームを Web／アプリ化」する依頼から、権利的に安全でルールが明快なトランプ系カードゲーム **ノイ（NEU）** を選定。まずオフラインを完成 → オンラインを追加する段階的方針。サーバー費用ゼロ・インストール不要で遊べることを重視。

### 主な機能
- **ルール**：上限 101／バーストでライフ −1／**ひとり負け・ひとり勝ちの2モード**／ライフ 1〜3・手札 3〜5・**2〜7人**を設定可
- **カード**：数字 1〜9・10/J/Q/K(+10〜+40)・−10/−20・101・パス・スキップ・**ダブル**・リバース・リセット・**ショット**（全22種 × 各4枚 ＝ 88枚）＋ **手札こうかん**（指定相手と手札を交換・1人1回）
- **対戦形態**：**同一端末パス＆プレイ**（本人確認・覗き見防止）／ **CPU 対戦（3段階）** ／ **オンライン対戦**（PeerJS・ルームコード・切断時は CPU が肩代わり）
- **演出**：カード／合計ゲージ／特殊カード／バースト／勝敗の演出、効果音、日本語読み上げ、**手番制限 30＋5 秒**
- ゲームロジックは純粋関数のエンジンに分離（UI とオンラインのホストで共用）

### 苦労した点
- 実行環境でブラウザ確認ができず → **エンジンの自動テスト＋全設定の総当たり自動対局＋SSR 描画**で品質を担保
- GitHub Pages のデプロイ設定・権限（`Resource not accessible by integration`／未ログインの 404／個人設定とリポジトリ設定の取り違え）に連続で遭遇 → 解決
- 手札こうかんで AI が交換相手を指定せず **無限ループの重大バグ** → 発見・修正
- 雀魂風の円卓レイアウトで、アバターと枠線の重なり・多人数／長い名前のはみ出し・スマホ最適化を反復調整
- 共有サーバーで `.js` の MIME エラー → **全内蔵の単一 HTML ビルド**で回避

## 起動・公開

```bash
npm install
npm run dev                 # 開発（http://localhost:5173）
npm run build               # 本番ビルド（GitHub Pages 用 base=/board-game/）
npm test                    # エンジンのテスト
SINGLEFILE=1 npx vite build # 全内蔵の単一 index.html（共有サーバー向け）
```
