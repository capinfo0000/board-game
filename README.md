# ノイ（NEU）🃏

既存のカードゲーム「ノイ（NEU）」をブラウザで遊べるようにした Web アプリです。
PC・スマホ（縦持ち）対応。**同じ端末で順番に回して遊ぶパス＆プレイ**と **AI（NPC）対戦**に対応しています。

> オンライン対戦（ルームコード）は次のステージで追加予定です。

## 遊び方

手札からカードを1枚出して、**場の合計**を増やしていきます。
合計が **101 を超える**札しか出せなくなったら **バースト**（ライフ −1）。
ライフ（最初は3）が 0 になると脱落し、**最後の1人が勝ち**です。

### カード一覧

| カード | 効果 |
|---|---|
| 1〜9 | その数字を足す |
| 10 / J / Q / K | +10 / +20 / +30 / +40 |
| −10 / −20 | 場の合計を下げる（0で止まる） |
| 101 ⚡ | 場の合計を一気に 101 にする |
| ⏭ パス | 合計を変えずに手番を終える |
| 🚫 スキップ | 次の人を飛ばす |
| ➕➕ 次2枚 | 次の人は強制で2枚出す（累積なし） |
| 🔄 リバース | 順番を逆にする（2人時は実質スキップ） |
| 1️⃣ リセット | 場の合計を1に戻す |
| 🎯 指名 | 次に出す人を指名する（自分以外） |

デッキは **全22種 × 各4枚 = 88枚**。

### 🌀 必殺技（1人1回）

自分の手番に発動すると、**全員の手札を右回りで総入れ替え**します。発動するとその手番は終了します。

## 開発・起動

```bash
npm install      # 依存関係のインストール
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # 本番ビルド（dist/）
npm run preview  # ビルドの確認
npm test         # ゲームエンジンのテスト
```

## 技術構成

- フロントエンド：**React + Vite**
- ゲームロジック：`src/game/`（UI とサーバーの両方から使える純粋ロジック）
  - `cards.js` … カード定義・デッキ生成
  - `engine.js` … ルール・状態遷移
  - `ai.js` … AI（弱い／普通／強い の3段階）
- UI：`src/components/`

## ルール設定（既定値）

- 上限 **101** ／ ライフ **3** ／ 手札 **5枚** ／ 人数 **2〜7人**（AIで席を埋め可）
- バースト後は場を0に戻し、全員に手札を配り直して次ラウンド（負けた人が次の親）
- マイナスで合計が0未満になる場合は0で止まる
- 山札が尽きたら捨て札をシャッフルして補充

## オンライン対戦（ルームコード）🌐

別々の端末で対戦できます。**サーバー不要**（PeerJS / WebRTC の P2P）なので、この GitHub Pages のまま動きます。

1. ホストが「部屋を作る」→ **4文字のルームコード**が表示される
2. 参加者はコードを入力して参加（最大7人・AIも追加可）
3. ホストがルール（勝敗/ライフ/手札）を決めて開始
4. ゲーム進行はホスト端末が担当（手番30秒で自動・切断者はAIが肩代わり）

> 各プレイヤーには自分の手札だけが見えます（他人の手札はネットワーク上でも隠されます）。
