# ノイ（NEU）🃏

トランプを使った数字カードゲーム「ノイ（NEU）」を、ブラウザで遊べるようにした Web アプリです。
PC・スマホ（縦持ち）対応。**サーバー不要**で動きます。

🎮 公開URL： https://capinfo0000.github.io/board-game/

- 👥 **2〜7人**（CPU で席を埋め可）
- 📱 **同一端末パス＆プレイ**（覗き見防止つき）
- 🤖 **CPU 対戦**（弱い／普通／強い）
- 🌐 **オンライン対戦**（PeerJS による P2P・ルームコードで別端末と対戦）

> 制作の経緯・苦労した点・改善の記録は [`docs/制作の記録.md`](docs/制作の記録.md) を参照。

## 遊び方

手札からカードを1枚出して、**場の合計**を増やしていきます。
合計が **101 を超える**札しか出せなくなったら **バースト**（ライフ −1）。

このゲームは勝敗の決め方を選べます：
- **😵 ひとり負け**：最初にライフが 0 になった人が負け → その時点で終了（残りは全員勝ち）
- **🏆 ひとり勝ち**：脱落者を出しながら続行し、最後まで残った1人が優勝

カードを出したら手番の終わりに山札から1枚引きます。山札が尽きたら捨て札をシャッフルして戻します。
手番には**制限時間（30秒＋ラスト5秒）**があり、時間切れで自動的に手が打たれます。

### カード一覧（全22種 × 各4枚 ＝ 88枚）

| カード | 効果 | 枚数 |
|---|---|:--:|
| 1〜9 | その数字を足す | 各4 |
| 10 / J / Q / K | +10 / +20 / +30 / +40 | 各4 |
| -10 / -20 | 場の合計を下げる（0で止まる） | 各4 |
| 101 ⚡ | 場の合計を一気に 101 にする | 4 |
| ⏭ パス | 合計を変えずに手番を終える | 4 |
| 🚫 スキップ | 次の人を飛ばす | 4 |
| ➕➕ ダブル | 次の人は強制で2枚出す（下記参照） | 4 |
| 🔄 リバース | 順番を逆にする（2人時は実質スキップ） | 4 |
| 1️⃣ リセット | 場の合計を1に戻す | 4 |
| 🎯 ショット | 次に出す人を指名する（自分以外） | 4 |

**ダブル（次の人2枚）の詳細**
- 受けた人は2枚出す。ただし**特殊カード（スキップ/リバース/リセット/パス/ショット）を出せば1枚でOK**で、「2枚出す番」は次の人へ移る。
- **ダブルでは返せない**（2枚出しの番ではダブルを出せない）。
- 数字・±・101 を出した場合は2枚必要。**2枚出したターンに引けるのは1枚**（手札が1枚減る）。

### 🔁 手札こうかん（1人1回）

自分の手番に使うと、**指定したプレイヤーと手札をまるごと交換**します。
**交換したあとは、続けてカードを出します**。出せるカードが無いときの立て直しにも使えます。

## 開発・起動

```bash
npm install      # 依存関係のインストール
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # 本番ビルド（dist/）
npm run preview  # ビルドの確認
npm test         # ゲームエンジンのテスト（node --test）
```

## 公開・デプロイ

- **GitHub Pages**：`main` への push で `.github/workflows/deploy.yml` が自動デプロイ。
- **任意の静的ホスト（CoreServer 等）**：相対パスでビルドして `dist/` の中身をアップロードするだけ。
  ```bash
  npx vite build --base=./   # どのフォルダに置いても動く相対パス版
  # 生成された dist/ の中身（index.html と assets/）を公開ディレクトリへ
  ```
  オンライン対戦（WebRTC/PeerJS）を使う場合は **https** での公開を推奨。

## 技術構成

- フロントエンド：**React + Vite**
- ゲームロジック：`src/game/`（UI とオンラインのホスト双方から使える純粋ロジック）
  - `cards.js` … カード定義・デッキ生成
  - `engine.js` … ルール・状態遷移
  - `ai.js` … CPU（弱い／普通／強い）
- オンライン：`src/net/`（PeerJS ラッパー＋手札を秘匿する redact）
- 音・読み上げ：`src/sound.js`（Web Audio API ＋ Web Speech API）
- UI：`src/components/`

## ルール設定（既定値）

- 上限 **101** ／ ライフ **1〜3**（既定1） ／ 手札 **3〜5枚**（既定3） ／ 人数 **2〜7人**
- 勝敗：**ひとり負け**（既定）／ ひとり勝ち
- バースト後は配り直して次ラウンド（負けが確定したら終了）
- マイナスで0未満になる場合は0で止まる
